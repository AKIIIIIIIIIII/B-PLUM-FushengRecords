# 生成浮生录

这是协调入口，不复制其他 Skill 的详细规则。

## 选择票根来源

优先复用用户提供或当前对话刚生成的同名 PNG 与 JSON。没有现成票根时，只问一次，让用户选择：

- 先使用 `../make-life-ticket` 制作自己的真实人生票根；
- 使用 `../implant-sample-tickets` 准备默认过去 5 张、未来 5 张虚构样票。

不要直接创建最终空册后宣称“浮生录完成”；完成品必须至少收录一张票。

## 协调顺序

### 已有票根

1. 使用 `../bind-life-album` 创建空册。
2. 使用 `../collect-life-tickets` 收录票根。
3. 构建、验证并启动本地预览。

### 制作个人票根

1. 按 `../make-life-ticket` 逐张完成确认和出票。
2. 用户可以继续制作；只有用户说“收录成册”后才创建空册。
3. 使用 `../collect-life-tickets` 一次收录本轮全部成功票根。
4. 构建、验证并预览。

### 植入样票

1. 使用 `../bind-life-album` 创建空册。
2. 使用 `../implant-sample-tickets` 展示完整随机出票单并等待“出票”。
3. 植入完成后构建、验证并预览。

任何分支失败时保留已生成的票根文件，报告失败阶段；不要删除或覆盖用户旧藏本，不自动发布。
