# 浮生录视觉规则

- 使用简约东方仙侠气韵：深靛、墨黑、旧金、云海与远处仙阁。
- 初始只显示合上的古籍，让用户亲手开卷。
- 固定两枚书签：过去、未来。
- 两枚书签默认同高；选中项统一向下露出（桌面约 10px、移动端约 8px），未选中项在可悬停设备上只下移约 3px。选中项悬停时不得再次跳动，触屏不得残留悬停高度。
- 中文使用令东齐伋复刻体；阿拉伯数字与英文使用思源宋体。动态 JSON 文字也遵守。
- 不使用英文界面，不使用醒目的现代按钮，不增加黄色发光块。
- 过去篇桌面双页必须零间隙相连，以连续纸色、中央压痕和装订阴影形成同一本摊开的书；书脊处不得露出页面背景。书册以 1160×650 为桌面 1 倍基准并始终等比缩放。书页保留纸纹与水波纹，但纹理只能位于票根下方。
- 票根 PNG 始终完整等比例显示；不裁切、不变形、不覆盖时间标签。
- 过去篇按可用空间自适应：宽敞时每半页三张，窄屏或低矮窗口每半页两张；同一页中的票根自然排列、间距均匀。若票根数量不足以填满当前半页，先计算票根组整体高度，再在半页可用高度内垂直居中；两张票必须作为一组居中，不得因为空位而上贴或下沉。
- 票托随票根等比例缩放并与票面位置匹配；票托和票面之间保留清楚但克制的视觉层次，不得错位或挤在一起。
- 双页布局使用带正反面的 3D 纸页绕书脊旋转；单页布局不论设备类型，均使用当前页与目标页同时交错的左右滑动，不渲染纸张背面或 3D 翻面。不用按钮或页角点击直接替换内容；整张纸面支持鼠标轻划、触屏轻扫与触控板横滑，手势完成后播放完整动画，不呈现按住拖动或页面跟手效果。单页滑出内容须由书册边界裁切，不使用可自由滚动的横向容器或纵向连续票根列表。动画提交后票根不得再次淡入、位移或闪烁。
- 未来篇票根进入时先显示完全空镜，滚动后再渐显。纵深遵循“下方远景—中央近景—上方远景”：中央吸附票根放大至 1.12 倍，上方远去票根沿缓动轨迹逐渐缩至约 0.28 倍、向山景中心消失点收拢并自然淡出，最远只加约 1.8px 轻微虚化；不得线性快速飞出或越远越向两侧分散。以普通票短边为响应式基准；长宽比达到 2:1 以上的票视为细长票，其长边固定为普通票短边的 2 倍，短边按原始比例反推。未来票的尺寸容器是唯一尺寸来源，基础尺寸须预留 1.12 倍变换空间；导入票面必须移除通用票面的固定 `aspect-ratio`，票面与图片边界不得超出容器。票面始终等比例居中，不得裁切或拉伸；若票根超出视口安全宽高，只允许整张等比例缩小。
- 联络窗口表现为一张半透明古籍宣纸签，只在合书首页出现。默认标题“联络造册人”，正文“若欲量身造册，敬请移步访造册人。”；茶钱二维码与个人网站按钮分区呈现，不显示裸网址。桌面 1 倍基准宽度为 160px、二维码为 118px，默认透明度 60%，悬停或聚焦时提高至 78%；手机画布中以右上角为原点将整张签缩至 0.78 倍，内部内容与留白同步缩放，不得反向放大单项尺寸或遮挡居中的封面。二维码始终完整等比，不重绘、不遮盖定位点。
- Three.js 云层、灯火和远景使用固定种子生成基础构图；可以保留轻微连续动画，但刷新页面或新建藏本时不得随机改变场景布局。
- 常规页面布局、尺寸、间距、响应式和交互状态使用 Tailwind；全局 CSS 只保留字体、主题变量、纸张纹理、伪元素、复杂动画和 Three.js 画布等必要规则。
- 前景界面使用 1440×900 桌面画布或 390×844 手机画布，以 `min(窗口宽比, 窗口高比, 1.15)` 居中等比缩放；Three.js、雾层与全屏遮罩不进入缩放画布。封面 290px、联络签 160px 是桌面 1 倍基准；除手机联络签按整体比例缩放外，文字和操作区域保留现有可读与可触控下限。
- 基础版只允许修改藏本名称、副标题、版次和联络链接；重新设计主题属于定制范围。
