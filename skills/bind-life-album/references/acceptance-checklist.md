# 验收清单

- 合书、开卷、过去和未来均可操作。
- 1440×900 下封面、联络签和过去书册分别保持 290px、160px、1160×650 的 1 倍基准；1920×1080 及更大窗口最多放大到 1.15 倍。
- 768×1024、390×844、320×568 和低高度横屏下，前景按宽高较紧的一边等比缩放且居中，封面、联络签、工具栏、书册、未来长廊和详情均不溢出；手机联络签整体缩放后仍固定在右上独立区域，不与居中封面、品牌或开卷提示重叠；Three.js 与全屏遮罩仍铺满实际窗口。
- “过去 / 未来”书签默认同高，选中项向下露出；连续切换、悬停和触屏点击时方向一致且无二次跳动。
- PNG 与 JSON 能按同名和 ticketNumber 配对。
- 出票与导入均执行“过去两种、未来三种”；过去章节方票、未知票型及 JSON/PNG 票型冲突会被明确拒绝且不写入藏册。
- 过去与未来分类正确。
- 过去按发生时间排序；空间足够时每半页三张，窄屏或低矮窗口自动改为两张；票根不足时票根组在半页可用高度方向居中，两张票尤其不能贴顶或贴底。
- 过去票根自然排列、间距均匀，票托与票面匹配，票根完整且无重叠、无裁切。
- 桌面过去篇左右页零间隙相连，中央书脊连续自然，不露出页面背景；整张纸面可用鼠标轻划、触屏轻扫或触控板横滑，左右方向键亦可翻页，无可见上一页／下一页按钮或页角点击热区，纸页不跟随指针拖动。
- 连续改变窗口尺寸时书册保持 1160:650，缩放后可用页高不足 500px 时每页改为两张，阅读位置不跳失；手机联络签及二维码按整张便签同比缩放，其他主要操作区域不低于 44px。
- 双页翻页纸张正反面与前后页内容对应；任何单页布局均不出现 3D 翻面或纸张背面，前进时当前页左出、目标页右入，后退时方向相反，滑出内容不越过书册边界。两种模式均在动画完成后才更新页码。
- 普通点击每张票根均能打开对应详情，指针只在形成轻扫后才被捕获并抑制残留点击；垂直移动、轻微抖动、超时、未达阈值、取消手势或到达首尾时不跳页。触控板一次横滑只换一页，惯性滚动不连翻。动画完成后票根稳定显示，不再次淡入、位移、闪白或闪烁；单页模式不使用横向滚动吸附或纵向连续票根列表。
- 书页纹理不覆盖任何票根。
- 未来初始完全不露出票根，滚动后从下方远景渐显并在中央以 1.12 倍吸附；越过中央后持续向上但逐渐减速，平滑缩至约 0.28 倍，横向先略有漂移再向中心消失点收拢，并在约 0.4—2.4 个距离单位间自然淡出、最多轻微虚化 1.8px；低透明票根不可点击。细长票以 2:1 长宽比为判定阈值，长边为普通票响应式短边基准的 2 倍，短边按原比例反推；未来票基础容器为 1.12 倍近景预留安全空间，容器、导入票面和图片实际边界一致，不继承通用票面的固定横向比例，不溢出、不裁切、不变形。
- 点击票根能打开详情，关闭按钮与 Escape 可用。
- 拖放、文件选择和本地保存可用，并持续标注“仅保存在此浏览器”。
- “清空票根”可清除本地票根并隐藏默认票根，刷新后仍为空；“恢复默认票根”只恢复网站自带票根，且本地同编号票根优先。
- 清空、恢复、置入成功或失败等状态提示约 4.2 秒后自动消失。
- 中文、数字和英文遵守固定字体规则。
- 联络便签只在合书首页显示；桌面 1 倍基准宽度 160px、二维码 118px，手机画布中以右上角为原点整体缩至 0.78 倍，内部元素比例不变且不遮挡标题或封面；默认透明度 60%，交互态 78%；正文使用“若欲量身造册，敬请移步访造册人。”，茶钱二维码与个人网站按钮分区呈现，不显示裸网址。
- 刷新页面或新建藏本时，Three.js 云层、灯火与远景的基础构图保持一致。
- 桌面与移动布局均无横向溢出。
- 结构检查脚本通过。
- npm run build 通过。
- 默认只交付本地网站；未得到明确指示时不得发布。
- 公开分发前保留并核对所有随包字体的许可文本。
