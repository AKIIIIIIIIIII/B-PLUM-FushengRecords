# 验收清单

- 合书、开卷、过去和未来均可操作。
- “过去 / 未来”书签默认同高，选中项向下露出；连续切换、悬停和触屏点击时方向一致且无二次跳动。
- PNG 与 JSON 能按同名和 ticketNumber 配对。
- 过去与未来分类正确。
- 过去按发生时间排序；空间足够时每半页三张，窄屏或低矮窗口自动改为两张；票根不足时票根组在半页可用高度方向居中，两张票尤其不能贴顶或贴底。
- 过去票根自然排列、间距均匀，票托与票面匹配，票根完整且无重叠、无裁切。
- 移动端过去篇可横向翻页并自然吸附，不把票根纵向堆叠成过长页面。
- 书页纹理不覆盖任何票根。
- 未来初始完全不露出票根，滚动后渐显并吸附；细长票以 2:1 长宽比为判定阈值，长边为普通票响应式短边基准的 2 倍，短边按原比例反推；未来票的容器、导入票面和图片实际边界一致，不继承通用票面的固定横向比例，不溢出、不裁切、不变形。
- 点击票根能打开详情，关闭按钮与 Escape 可用。
- 拖放、文件选择和本地保存可用，并持续标注“仅保存在此浏览器”。
- “清空票根”可清除本地票根并隐藏默认票根，刷新后仍为空；“恢复默认票根”只恢复网站自带票根，且本地同编号票根优先。
- 清空、恢复、置入成功或失败等状态提示约 4.2 秒后自动消失。
- 中文、数字和英文遵守固定字体规则。
- 联络便签只在合书首页显示，不遮挡标题；默认文案与网址连续显示为“若要定制册子请联系：https://b-plum.com/”。
- 桌面与移动布局均无横向溢出。
- 结构检查脚本通过。
- npm run build 通过。
- 默认只交付本地网站；未得到明确指示时不得发布。
- 公开分发前保留并核对所有随包字体的许可文本。
