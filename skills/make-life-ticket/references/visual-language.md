## 总体基调

固定使用“当代编辑设计借用票券结构”基调。它不是旧海报复刻，也不是做旧滤镜：以现代编辑秩序、留白与材料细节为主，只借用票根的轮廓、撕票结构与凭证逻辑。

- 使用干净的暖骨白／象牙白棉纸、深炭黑或深墨绿细线与克制朱红；主画面仍可根据用户情绪使用一个低饱和辅助色，例如石油蓝、灰青或烟陶土。
- 以大留白、不对称网格、精确对齐和克制的字号反差建立高端感；不要靠堆满花纹制造“设计感”。
- 主结构只保留一条主框、少量分隔线、一个小型圆章和一条朱红规则；避免多层套框、重复框线、装饰性花纹或条码感元素。
- 将画面控制在骨白、炭黑、朱红与一至两个低饱和辅助色内，避免全画面棕黄／褐色统治。
- 主图使用细而干净的深炭黑墨线、低饱和平涂与少量局部排线；避免粗黑轮廓、夸张表情、漫画式动作和怀旧广告半点。
- 纸张只保留低对比的纸浆纤维与极轻油墨吸收边缘；半点只用于主图阴影或色块内，不能铺满票面。主图可叠加极轻暖纸罩染以融入票纸，但不能泛黄、脏化或产生密集颗粒。
- 以极轻的环境阴影和压印层次表现纸张厚度：票形外沿、切角、撕票线／副券分隔与主画面内框可有柔和的 1–3 px 阴影或浅压痕；阴影应低对比、方向一致，只让票根从透明背景与纸面层次中轻微浮起，不能形成悬浮卡片、高光塑料或厚重投影。
- **版式锁定**：保留既有三种票型各自的朱红色排版、标题块、框线、信息区、撕票线、副券与章的位置和比例。更新只能改变纸张材质层、压印层和主图印刷融合层；不得借“视觉语言更新”修改结构、留白、字号层级或朱红色构图。
- 留白必须安静、干净，不能被纹理、边框或装饰填满；保持可收藏的整洁感，不制造污渍、破损、仿古裂纹或难以辨认的文字。
- 票券强调色固定为朱红 `#A63D32`，搭配酒红 `#6F2A25` 与褪色陶红 `#C97868`；只用于外框、状态章、画面错位底版、标题色块、字段标签与一条连接线。
- 不使用金色、金箔、金属高光或发光效果。
- 避免霓虹、赛博朋克、光滑塑料和强 3D。

复古是对既定“寓言卡绘式”的追加处理，不得替换绘画风格或用户输入映射。

## 票形

### 幕间长票 `intermission-stub`

- 输出尺寸：1800 × 600 px，约 3:1 横向。
- 使用轻微圆角。
- 在右侧约四分之一处设置副券区。
- 用竖向虚线和浅半圆缺口表现撕票线。
- 不复制任何参考票券的具体轮廓或装饰。

### 胶片齿票 `film-edge`

- 输出尺寸：1600 × 640 px，约 2.5:1 横向。
- 在左右中部设置对称浅缺口。
- 在上下边缘使用细小、均匀的胶片式齿孔。
- 保持左右视觉平衡，不设置突出的独立副券轮廓。

### 章节方票 `chapter-pass`

- 输出尺寸：1200 × 1500 px，约 4:5 竖向。
- 使用轻微切角。
- 在左右中部设置半圆缺口。
- 在标题区上方使用一条横向撕票虚线；虚线只作结构分隔，不穿过标题或状态章。
- 不使用上下连续齿边。

票形以外区域保持透明。

## 排版

### 字体系统

全票中文统一使用内置令东齐伋体 `qiji-combo.ttf`：产品名、票种、标题、时间、地点、记录、字段标签和状态章都不得混用其他中文字体。齐伋体不包含拉丁字母与阿拉伯数字，因此英文、日期数字、票号和文件格式字符统一使用内置思源宋体简体中文 Regular；不要再混入其他无衬线字体，也不要为了装饰额外增加英文。

齐伋体不包含全角逗号 `，`。票面渲染时将中文全角逗号 `，` 与半角逗号 `,` 显示为齐伋体可用的顿号 `、`；只改变 PNG 上的显示，不修改 JSON 中保存的用户原文。句号 `。` 保持不变。

内置字体均保留 OFL 1.1 授权文件。不要临时下载其他字体，也不要使用来源或商用范围不清楚的字体。字号层级至少形成“标题／关键信息／字段标签”三档：标题最大；时间只比地点略大或同级；地点、记录、票种和凭证信息必须能在缩略预览中读清，不能为了留白缩成微型字。

### 共通编辑规则

- 使用不对称编辑网格，不把每一项都装进独立矩形框。
- 每张票只允许一个主要色块、一个主画面和一个焦点标题；其他元素退居辅助层级。
- 标题可在主画面边缘跨栏 5%–12%，但必须有纯色承托并保持清晰。
- 票号沿独立的窄轨道排列，可以旋转；状态以细线圆章或实色小签呈现，不模仿真实机构印章。
- 可使用裁切角标、套印圆、短横线、放射线或与内容相关的简化符号；一次最多使用两类装饰。
- 装饰必须来自地点、时间或视觉元素。没有依据时只使用线、圆和编号，不自动增加星月、占星或神秘学符号。
- 辅助标签统一使用中文，例如“时间”“地点”“记录”“编号”；不得增加英文装饰语、宣传语、价格、机构名或虚构活动信息。

### 幕景三联式 `stage-triptych`

仅用于 `intermission-stub` 与 `film-edge`。使用约 34%／46%／20% 的三段基础网格，但允许标题色块和装饰线跨过分栏。

- 信息区：产品名和票种以微型题头出现；时间或标题形成主要层级；地点与记录沿同一左边线排列。
- 主画面区：使用带内框的非满版裁切；用一条强调色色块把标题与画面整合，而不是简单在图片底部盖黑条。
- 凭证区：状态章置于上方；下方只保留两个左对齐的信息组——“制票日／下单日”及日期、“票根编号”及完整编号。标签在上、内容在下，并以一条细线分隔。不要再放笼统的“凭证”总标题，不要重复竖排编号或只显示四位尾号。幕间长票使用撕票线；胶片齿票只使用视觉分栏。
- 允许一条细装饰线穿越信息区与画面区，形成“人生一帧延续到下一帧”的视觉隐喻。
- 当宇宙订单票选择“不显示时间”时，完全移除时间项目，让标题进入信息区的主要位置；不要在主画面重复标题。
- 当一句话记录缺失时，保留自然留白，不用其他文案填补。

### 章节海报式 `chapter-poster`

仅用于 `chapter-pass`。

- 顶部题头：用细线与微型标签显示“人生票根”和票种，不做居中证书式题头。票种右侧须保留至少一个中文全角字的安全边距，避免贴近票形外框。
- 中央标题：让 4–12 字标题成为全票最大文字，可分成 2–3 行；使用不对称对齐。状态章固定置于标题右侧并与标题垂直居中，不放在题头或单独分隔区。
- 中部画面：使用预先按约 3:1 横向安全区生成的场景、完整上身人物或象征性图像带；人物头部、手部和关键道具不得被横向图像带裁断。以错位内框或 1–2 px 套印边表现旧印刷，避免普通相框感。
- 下部信息格：显示时间、地点、票根编号、制票日或下单日。“时间”“地点”“制票日／下单日”“编号”使用统一且清晰可读的字段标签字体、字号、字距和强调色；字段内容须比标签明显更大。日期数字使用稍小的思源宋体，票号使用清晰可读的思源宋体，并让两者与同一内容列对齐。
- 一句话记录存在时，使用一条独立横向区域；不存在时移除整条区域。
- 当时间隐藏时，移除时间格，让地点或状态区域自然扩展，不留下空框。

不要复制参考图的具体字体组合、条码、宣传语或装饰画。所谓“高端”以克制、秩序和材质细节体现，不使用仿奢侈品牌字标或现成品牌视觉。

## 绘画风格

固定使用“寓言卡绘式” `symbolic-card-illustration`：

- 使用清晰墨线、平涂色块和少量排线阴影。
- 使用正面、舞台式或象征性的原创构图。
- 将人物、场景、植物、动物、建筑和天体组织成一幅人生寓言。
- 保持画面内无任何文字、数字、牌名、牌号或可识别标志；所有票面文字后续确定性排版。
- 不把画面做成占卜结果，也不暗示某个象征具有固定命运含义。

往昔纪念票可以呈现更安定、被保存下来的构图；宇宙订单票可以呈现更开放、仍有延伸空间的构图。优先服从用户给出的情绪，不按票种强制固定颜色。

## 输入映射

| 用户输入 | 画面作用 |
|---|---|
| 这一幕是什么 | 决定中央人物、动作、事件与主要物件 |
| 时间 | 决定季节、天色、植物状态或环境线索，不强行画成钟表 |
| 地点或场域 | 决定背景建筑、地貌或空间结构 |
| 情绪 | 决定色彩、光线、人物姿态和画面节奏，不显示为文字 |
| 视觉元素 | 优先转化成具体道具、植物、动物或象征物 |
| 用户照片 | 转化为插画人物并保留关键可辨认特征，不直接把原照裸放在票面 |
| 一句话记录 | 只用于票面文字，不据此擅自增添剧情 |

从用户原话提取 3–5 个核心元素。允许补充少量能连接场景的细节，但每个细节都要能说明与事件、地点、时间或情绪的关系。不要自动堆放无关的星月、占星、宗教或神秘学符号。

在确认单中先展示一句画面构想；用户修改后，使用修改后的版本生成。

## 选择与复现

- 用户未指定票形时，在三种票形之间等概率随机选择。
- 用户明确指定票形时服从选择。
- 用户要求“换一个”或“重新随机”时重新选择。
- 先确定票形，再按相容关系选择排版，不独立随机不相容组合：
  - `intermission-stub` → `stage-triptych`
  - `film-edge` → `stage-triptych`
  - `chapter-pass` → `chapter-poster`
- 将最终 `shapeStyle`、`layoutStyle` 和 `imageStyle` 写入 JSON。重新渲染同一 JSON 时保持不变，除非用户明确要求更换。

配色、边框小图案和装饰线不进行无意义随机；根据当次用户输入和画面构想生成。

## 原创边界

- 只借鉴常见票券、旧印刷品和象征卡牌的通用视觉语法。
- 不复制参考图片的具体构图、人物姿势、道具组合、条码、字体组合或装饰。
- 不使用具体塔罗牌名、牌号、牌组标志、经典牌面构图或特定角色。
- 不在图像提示词中要求模仿在世艺术家、特定牌组或受保护品牌。
- 不把用户提供的参考图片打包进 Skill；仅将本文件中的抽象规则作为生成依据。
